# Loja_GLEM

👕 GLEM Rockwear é uma loja virtual de roupas desenvolvida como projeto de programação, com o objetivo de simular uma experiência de compra online.

O projeto permite visualizar produtos, consultar informações das peças e realizar o gerenciamento de um carrinho de compras.

📋 Sobre o projeto
